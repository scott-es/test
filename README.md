## basic-pnpm-project

### Requirements

- **Node**: `20.11.1` (enforced via `package.json#engines` + `.npmrc` `engine-strict=true`)
- **pnpm**: via `packageManager` in `package.json`

### Setup

```bash
pnpm install
```

### Run

```bash
pnpm dev
```

### Build / Start

```bash
pnpm build
pnpm start
```
